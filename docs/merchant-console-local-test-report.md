## 新增覆盖

- 关闭／开放日期的幂等性，保留营业窗口、原始屏蔽区间和已有预约占用；重复操作不重复写审计。
- 商家取消后释放占用，但日期继续关闭；已取消预约在开始时间之后重复取消仍成功。
- 关闭日期禁止新预约；未生成日期、休息日、历史日期不能通过开放操作恢复。
- 可预约、约满、暂无服务、已无可预约时段、营业结束的区分。
- 当日列表跨页完整返回 200 条，201 条明确拒绝；取消历史超出列表上限时，当日有效预约统计仍准确。
- 返回字段不包含用户内部标识和幂等标识；其他资源的预约详情禁止访问。
- 关闭日期与创建预约并发时，最终关闭标记、预约记录和占用保持一致（本地乐观事务模拟）。
- 云函数入口基于可信身份授权；普通用户、停用用户、账号绑定不匹配均无法调用商家接口，缺失微信身份被拒绝。
